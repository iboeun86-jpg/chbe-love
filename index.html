다른 계정으로 로그인 바꾸는 법
  1. 화면 맨 위에 '볼 수 있음'이 보이면, 지금 로그인한 계정이 초대받은 계정이 아니라는 뜻이에요.
  2. 먼저 방장에게 초대받은 이메일이 무엇인지 물어봐요.
  3. Claude 앱: 이 창을 닫고 → 왼쪽 위 메뉴(≡) → 맨 아래 내 이름 → 로그아웃 → 초대받은 이메일로 다시 로그인해요.
  4. 사파리·크롬: claude.ai 에서 왼쪽 아래 내 이름 → 로그아웃 → 초대받은 이메일로 다시 로그인해요.
  5. 로그인한 뒤 이 링크를 다시 열면 '볼 수 있음' 표시가 사라지고 주황색 안내도 없어져요.
  6. 지금 계정을 그대로 쓰고 싶다면, 방장이 공유 메뉴에서 지금 로그인한 이메일을 '편집 가능'으로 초대해도 돼요.

      함께 쓰는 사람 초대하기
      • 위 함께 쓰기 · 앱 설정의 초대 메시지 복사를 눌러 카톡으로 보내요.
      • 상대는 링크를 열고 처음이에요로 가입한 뒤 초대 코드를 넣으면 같은 달력을 같이 써요.
      • 습관 체크, 메모, 일정, 가계부가 모두 함께 보이고 몇 초 안에 상대 화면에도 들어가요.
      홈 화면에 앱으로 추가하기
      • 아이폰 Safari로 이 달력 링크를 열고 → 아래 가운데 공유 버튼(□↑) → 홈 화면에 추가 → 이름을 "습관 달력"으로 바꾸고 추가
      • 갤럭시·안드로이드 Chrome으로 링크를 열고 → 오른쪽 위 ⋮ → 홈 화면에 추가 → 추가 (삼성 인터넷은 아래 ≡ → 페이지 추가 → 홈 화면)
      • 아이콘을 원하는 사진으로 (아이폰) 단축어 앱 → 오른쪽 위 + → 동작 추가에서 'URL 열기' 검색해 추가 → URL 칸에 이 달력 링크 붙여넣기 → 위쪽 이름 옆 ▾ → 홈 화면에 추가 → 작은 아이콘을 눌러 사진 선택 → 원하는 사진 고르고 이름 적고 추가. 이렇게 만든 아이콘은 Safari 탭으로 열려요.
      • 아이콘을 원하는 사진으로 (갤럭시) 기본 기능으로는 안 되고, Play 스토어의 Shortcut Maker 같은 앱에서 '웹 주소' → 링크 붙여넣기 → 아이콘을 내 사진으로 바꾸고 홈 화면에 추가하면 돼요.
      • 카톡 안에서 열었다면 오른쪽 아래 ⋯ → 다른 브라우저로 열기로 사파리·크롬에서 열어 주세요.
      인원이 꽉 찼어요이 달력은 정해진 인원까지만 같이 기록할 수 있어요. 지금은 보기만 할 수 있어요. 방장에게 자리를 요청해 주세요.
